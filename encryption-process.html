02 — Encryption Process

SubBytes, ShiftRows, MixColumns, AddRoundKey — one full round, worked end to end.

AES is an iterated cipher: the same four operations run over and over, each one pushing the state a little further from the plaintext. Here's the first round, byte by byte, using the same key that Key Expansion stretched into eleven round keys.

The four operations

Every round after the first runs the same sequence. Round 0 is just the initial whitening — a single AddRoundKey before anything else happens.

SubBytes

Every byte in the state is swapped for its corresponding value in the AES S-box — a fixed 16×16 substitution table. This is the cipher's only non-linear step.

ShiftRows

Each row of the state is rotated left, by an amount equal to its own row index: row 0 stays put, row 1 shifts by one, row 2 by two, row 3 by three.

MixColumns

Each column is multiplied against a fixed 4×4 matrix in the Galois field GF(2⁸), spreading each byte's influence across the whole column.

AddRoundKey

The state is XORed, byte for byte, against the round key that Key Expansion produced for this round.

MixColumns

Each column is run through the same fixed matrix, multiplying in GF(2⁸) and XORing the results together:

b1 = (b1·2) ⊕ (b2·3) ⊕ (b3·1) ⊕ (b4·1)
b2 = (b1·1) ⊕ (b2·2) ⊕ (b3·3) ⊕ (b4·1)
b3 = (b1·1) ⊕ (b2·1) ⊕ (b3·2) ⊕ (b4·3)
b4 = (b1·3) ⊕ (b2·1) ⊕ (b3·1) ⊕ (b4·2)

Worked for the first column — 2a 7f cd 50 — using log/antilog tables for the GF(2⁸) multiplication:

b1 = (2a·2) ⊕ (7f·3) ⊕ (cd·1) ⊕ (50·1)
b1 = E(L(2a) + L(02)) ⊕ E(L(7f) + L(03)) ⊕ cd ⊕ 50
b1 = E(a6 + 19) ⊕ E(57 + 01) ⊕ cd ⊕ 50
b1 = 54 ⊕ 81 ⊕ cd ⊕ 50
b1 = 48

The same three formulas give b2 = c8, b3 = 24, b4 = 6c for that column. Repeating this for all four columns produces the full post-MixColumns state:
