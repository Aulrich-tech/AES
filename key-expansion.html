01 — Key Expansion

One 16-byte key becomes eleven round keys.

AES never encrypts with just your original key. Before the first round even starts, the key goes through a routine called key expansion that stretches it into a separate 16-byte round key for the initial step plus every one of the ten rounds — eleven keys total, all derived from the same 16 bytes.

The building blocks

Key expansion is built from four small, repeatable operations. Once you can do these four by hand, you can generate every round key that follows.

  • K — the original key, arranged as 4 words of 4 bytes each (w0, w1, w2, w3)
  • RotWord — rotate a 4-byte word up by one position
  • SubWord — replace each byte of a word using the AES S-Box
  • RCON — a round constant, XORed into only the first byte of the new word
  • EK — the expanded key: the growing list of words that becomes each round key
Only the first word of every new round key (w4, w8, w12…) goes through RotWord, SubWord, and RCON. The other three words in each round key are produced by a plain XOR with the word before them and the matching word from the previous round key — that's the shortcut that makes the rest of expansion fast.

Generating Round 1's key

Round 1's key is words w4–w7. Only w4 needs the full RotWord → SubWord → RCON treatment; w5–w7 are simple XORs.

RotWord the last column

Take the last word of the key (w3 = 09 cf 4f 3c) and rotate it up by one byte.

→

SubWord — run each byte through the S-Box

Look up each rotated byte in the S-Box table above.

cf → row c, col f → 8a
4f → row 4, col f → 84
3c → row 3, col c → eb
09 → row 0, col 9 → 01

XOR with w0 and RCON[1]

XOR the SubWord result against w0 (the key's first word) and RCON's first column (01 00 00 00) to get w4.

SubWord 8a 84 eb 01
RCON[1] 01 00 00 00

w4    a0 fa fe 17

XOR the rest forward

Every following word in this round key is just the new word XORed with the matching word from the original key — no RotWord or SubWord needed.
